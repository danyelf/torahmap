# Root mode doesn't highlight all search terms in sidebar

When searching for multiple terms (e.g., 'גוים,האריה'), only the first term gets highlighted in the sidebar. Example: II Kings 17:26 highlights 'הַגּוֹיִ֗ם' but not 'הָאֲרָי֗וֹת'.
