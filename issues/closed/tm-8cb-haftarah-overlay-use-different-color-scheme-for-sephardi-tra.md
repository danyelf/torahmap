# Haftarah overlay: use different color scheme for Sephardi tradition

Use slightly different colors for Sephardi haftarot vs Ashkenazi to reduce visual overlap and make it easier to distinguish between traditions. Currently both use the same color palette, making it hard to see which tradition a verse belongs to when both traditions use overlapping passages.
