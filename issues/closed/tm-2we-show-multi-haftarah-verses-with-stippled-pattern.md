# Show multi-haftarah verses with stippled pattern

Within each tradition, some verses appear in multiple parshiot: 31 verses in Ashkenazi, 41 in Sephardi. Main examples: Hosea 14 (Vayeilech + Vayetzei), Isaiah 54 (Noach + Ki Teitzei + Reeh). Use stippled rendering pattern (like multi-search hits) to show these overlaps. Update hover behavior to list all associated parshiot when hovering over a multi-haftarah verse.
