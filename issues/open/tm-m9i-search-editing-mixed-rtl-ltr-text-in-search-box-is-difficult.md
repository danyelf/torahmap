# Search: editing mixed RTL/LTR text in search box is difficult

The search input box has poor UX when editing mixed Hebrew (RTL) and English (LTR) text. Even basic cursor navigation around RTL words is difficult. Need to improve bidirectional text handling - possibly by setting dir='auto' or implementing better cursor/selection behavior for mixed-direction text.
