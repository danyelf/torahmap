# Multi-tractate / Seder layout question for Talmud

The tm-7la prototype proved single-tractate layout works (option C: perek-as-vertical-block, amud-per-row). Open question: how do tractates arrange within a seder, and how do the six sedarim arrange relative to each other?

The Tanakh's answer is "three horizontal sections (Torah / Nevi'im / Ketuvim)" — that may or may not translate to the Talmud's six sedarim. Investigate layouts that treat tractates as "books in a section" analog.

This is a design question, not just a coding task. Likely needs a small prototype iteration before the integration bead (`tm-f28x`) commits to a layout.
