# Add BDB support for full text search

Use the Brown-Driver-Briggs Hebrew lexicon (from https://github.com/eliranwong/unabridged-BDB-Hebrew-lexicon or similar sources) to enable canonical word search. This would allow searching by dictionary headwords/lemmas rather than just surface forms.
