Reading these numbers

  • Counts are weighted by Analytics Engine’s sample interval, so they are estimates.
  • There is no visitor id: each page load is a fresh visit, so one person reloading counts several times.
  • Only torahmap.org is counted, so pull-request previews and the dev server are left out; visits by the site’s own authors are included.
  • The last day is only as far as the time the data was fetched.
