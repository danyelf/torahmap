# Text Dating Overlay Design

**Issue:** tm-jkn
**Date:** 2026-01-27
**Status:** Design Complete

## Overview

Create an overlay that visualizes estimated composition dates for biblical texts using scholarly consensus. The overlay will use a geological metaphor (sediment layers) to show chronological stratification across the 5 major periods of biblical composition.

## Scholarly Approach

Follow the consensus dates from [Wikipedia: Dating the Bible](https://en.wikipedia.org/wiki/Dating_the_Bible) as the baseline. This provides:
- Widely accepted scholarly dates
- Complete coverage of all 39 books
- Sufficient detail for meaningful visualization
- Citable sources for transparency

Future refinements (separate issues) can add more detailed compositional analysis.

```json
    "citation": "https://en.wikipedia.org/wiki/Book_of_Isaiah#Composition"

```

**Field Definitions:**
- `book`: Book name (matches constants/books.ts)
- `chapters`: Range string ("1-11", "40-55", or "*" for all)
- `verses`: Range string ("1-17" or "*" for all in chapter)
- `era`: One of 5 era codes (see below)
- `date_bce`: Estimated date in BCE (used for shading within era)
- `note`: Scholarly explanation (shown on hover/sidebar)
- `citation`: URL to source (clickable link in sidebar)

### Runtime Data Format

Generated by build script, optimized for O(1) lookup in `public/data/text-dating.json`:

```json
{
  "notes": [
    {
      "id": 0,
      "note": "Priestly source (P), post-exilic redaction",
      "citation": "https://en.wikipedia.org/wiki/Dating_the_Bible#Genesis"
    },
    {
      "id": 1,
      "note": "Deutero-Isaiah, exile period",
      "citation": "https://en.wikipedia.org/wiki/Book_of_Isaiah#Composition"
    }
  ],
  "verses": {
    "Genesis": {
      "1": {
        "1": { "era": "persian", "date_bce": 450, "note_id": 0 },
        "2": { "era": "persian", "date_bce": 450, "note_id": 0 }
      }
    },
    "Isaiah": {
      "40": {
        "1": { "era": "exilic", "date_bce": 540, "note_id": 1 }
      }
    }
  }
}
```

**Rationale:** Notes are stored in a separate lookup table to avoid redundancy (many verses share the same scholarly note).

## Five Eras

Following Wikipedia's periodization (ending with Post-exilic/Hellenistic):

1. **Early Monarchic** (1000-722 BCE) - Unified kingdom, early divided monarchy
2. **Late Monarchic** (722-586 BCE) - Fall of Northern Kingdom to Babylonian exile
3. **Exilic** (586-538 BCE) - Babylonian captivity
4. **Persian Period** (538-331 BCE) - Return and Second Temple
5. **Hellenistic** (331-164 BCE) - Greek influence, Maccabean period

## Color Scheme

**Geological Metaphor:** Sediment layers showing composition history

```typescript
const ERA_BASE_COLORS: Record<string, Color> = {
  'early_monarchic': [0.35, 0.25, 0.15],  // Deep brown (oldest layer)
  'late_monarchic':  [0.65, 0.40, 0.20],  // Orange-brown
  'exilic':          [0.70, 0.45, 0.30],  // Rust/ochre
  'persian':         [0.75, 0.60, 0.45],  // Tan/beige
  'hellenistic':     [0.65, 0.65, 0.65],  // Light gray (newest layer)
};
```

**Shading Algorithm:**

Within each era, apply shading based on date:
- Older texts within an era are lighter
- Newer texts within an era are darker
- Shade factor ranges from 0.7 (start of era) to 1.0 (end of era)

```typescript
function getVerseColor(verse: VerseIdentity): Color | null {
  const data = lookupVerseData(verse);
  if (!data) return null;

  const baseColor = ERA_BASE_COLORS[data.era];
  const [rangeStart, rangeEnd] = ERA_DATE_RANGES[data.era];

  // Calculate position within era (0 = start, 1 = end)
  const position = (rangeStart - data.date_bce) / (rangeStart - rangeEnd);

  // Darken toward end of era
  const shadeFactor = 0.7 + (position * 0.3);

  return [
    baseColor[0] * shadeFactor,
    baseColor[1] * shadeFactor,
    baseColor[2] * shadeFactor,
  ];
}
```

## Build Script

**File:** `scripts/generate-text-dating.ts`

Converts human-friendly source data to runtime format:

1. Read `data/text-dating-source.json`
2. Read `public/data/tanakh-structure.json` (for verse counts)
3. For each source entry:
   - Parse chapter/verse ranges (handle "*" wildcard)
   - Expand to individual verses
   - Build notes lookup table (deduplicate)
   - Assign note_id references
4. Write `public/data/text-dating.json`

**Key Function:**

```typescript
function parseRange(rangeStr: string): number[] {
  if (rangeStr === '*') return []; // Handled specially
  if (!rangeStr.includes('-')) return [parseInt(rangeStr)];
  const [start, end] = rangeStr.split('-').map(n => parseInt(n));
  const result = [];
  for (let i = start; i <= end; i++) {
    result.push(i);
  }
  return result;
}
```

## Data Population Strategy

**Phase 0: Wikipedia Baseline** (this issue)
- Extract dating information from Wikipedia "Dating the Bible" article
- Provides complete coverage across all 39 books
- Uses scholarly consensus dates even if not maximally detailed
- Sufficient to launch the overlay and see patterns

**Future Refinements** (create as follow-up beads):
- Detailed Documentary Hypothesis layers for Torah
- Fine-grained compositional analysis for Major Prophets
- Individual research for Minor Prophets
- Complex multi-strata texts like Psalms, Proverbs

This approach gets the feature working immediately while allowing incremental scholarly improvements.
